# YouTube 채널 검증 · 수익화 분석기

YouTube 채널의 공개 지표를 불러와 수익성과 성장 지표를 추정하는 단일 파일 웹 앱입니다.
빌드 도구나 서버 없이 브라우저에서 바로 동작합니다.

## 바로 사용하기

https://hoyohoyo12-ui.github.io/certify-youtube/

## 기능

- **인기 채널 자동 탐색** — 조건에 맞는 채널을 찾아 목록으로 보여줍니다 (조회수·수익·구독자·참여율 순 정렬)
- **직접 입력해 분석** — 채널 URL이나 ID를 넣어 개별 분석
- **채널 비교 · 랭킹** — 여러 채널을 나란히 놓고 비교
- **지난 분석 기록** — "직접 입력해 분석"으로 돌린 결과가 자동 저장되어, 입력란 아래
  **📂 지난 분석 기록**에서 골라 **다시 보기**로 언제든 다시 열 수 있음
  (API 할당량을 쓰지 않음, 분석 당시 시점 기준으로 표시, 최근 15개까지 이 브라우저에만 저장)
- **내 카테고리** — 분석한 채널을 직접 만든 카테고리에 담아 두고, 카테고리 드롭다운에서 다시 불러보기
  (분석 결과를 함께 저장해 다시 볼 때 API 할당량을 쓰지 않음, 이 브라우저에만 저장됨)
  — **⬇ 내보내기 / ⬆ 가져오기**로 JSON 파일을 주고받아 다른 기기·다른 사람에게 옮길 수 있음 (가져오기는 기존 목록에 합침)
- **AI 훅 분석 (선택)** — 조회수가 유독 잘 나온 영상을 골라 제목·썸네일의 어떤 점이
  클릭을 유도했는지 AI로 해석 (Anthropic API 키 필요)
- 영상별 원본 데이터 확인, 라이트/다크 테마 지원

## 사용 방법

1. 위 링크에 접속합니다.
2. [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에서
   **YouTube Data API v3**를 활성화하고 API 키를 발급받습니다.
3. 페이지 상단의 입력란에 키를 붙여넣고 저장합니다.

키를 넣지 않아도 데모 데이터로 화면을 둘러볼 수 있습니다.

## API 키에 대하여

입력한 키는 **본인 브라우저의 `localStorage`에만 저장**되며, YouTube API를 호출하는 것
외에 어디로도 전송되지 않습니다. 이 저장소에는 어떤 키도 포함되어 있지 않습니다.
페이지의 "키 삭제" 버튼으로 언제든 지울 수 있습니다.

YouTube Data API는 하루 무료 할당량(기본 10,000 units)이 있으며, 분석량이 많으면
할당량이 소진되어 일시적으로 조회가 되지 않을 수 있습니다.

## AI 훅 분석에 대하여 (선택 기능)

채널 상세 화면의 영상 목록에서 **"훅 분석"** 버튼을 누르면 그 영상의 제목·설명·썸네일이
분석 시점에 [Anthropic API](https://console.anthropic.com/settings/keys)로 전송됩니다.
**YouTube 키와 달리 이 키를 저장하면 영상 데이터가 외부 서비스로 나갑니다.** 호출마다
소액이 과금되며, 이 기능을 쓰지 않아도 나머지 모든 기능은 그대로 동작합니다.
한 번 받은 훅 분석 결과는 이 브라우저에 저장되어, 같은 영상을 다시 열면 추가 과금 없이 바로 보입니다.

채널 중앙값 대비 조회수가 1.8배 이상인 영상에는 🔥 배지가 붙어 어떤 영상을 먼저
살펴볼지 힌트를 줍니다. 분석 결과는 공개 메타데이터만으로 낸 AI의 추정 가설이며
실제 알고리즘 동작이나 사실과 다를 수 있습니다.
