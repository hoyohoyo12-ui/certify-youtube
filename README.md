# YouTube 채널 검증 · 수익화 분석기

YouTube 채널의 공개 지표를 불러와 수익성과 성장 지표를 추정하는 단일 파일 웹 앱입니다.
빌드 도구나 서버 없이 브라우저에서 바로 동작합니다.

## 바로 사용하기

https://hoyohoyo12-ui.github.io/certify-youtube/

## 기능

- **인기 채널 자동 탐색** — 조건에 맞는 채널을 찾아 목록으로 보여줍니다
- **직접 입력해 분석** — 채널 URL이나 ID를 넣어 개별 분석
- **채널 비교 · 랭킹** — 여러 채널을 나란히 놓고 비교
- 영상별 원본 데이터 확인, 라이트/다크 테마 지원

## 사용 방법

1. 위 링크에 접속합니다.
2. [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에서
   **YouTube Data API v3**를 활성화하고 API 키를 발급받습니다.
3. 페이지 상단의 입력란에 키를 붙여넣고 저장합니다.

키를 넣지 않아도 데모 데이터로 화면을 둘러볼 수 있습니다.

## API 키에 대하여

입력한 키는 **본인 브라우저의 `localStorage`에만 저장**되며, YouTube API를 호출하는 것
외에 어디로도 전송되지 않습니다. 이 저장소에는 어떤 키도 포함되어 있지 않습니다.
페이지의 "키 삭제" 버튼으로 언제든 지울 수 있습니다.

YouTube Data API는 하루 무료 할당량(기본 10,000 units)이 있으며, 분석량이 많으면
할당량이 소진되어 일시적으로 조회가 되지 않을 수 있습니다.

## 로컬에서 실행

`index.html` 파일을 브라우저로 열기만 하면 됩니다. 별도 설치 과정은 없습니다.
