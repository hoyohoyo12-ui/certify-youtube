YouTube 채널 검증 · 수익화 분석기

전세계·대한민국 인기 급상승 차트에서 실제로 잘 나가는 채널을 자동으로 모아 미리보기로 띄웁니다. 거기서 고른 채널의 성장·성과 지표를 계산하고, 어뷰징(가짜 구독·조회) 신호를 점수화하며, 수익화(YPP) 자격과 예상 수익을 추정해 나란히 비교합니다.

API 키 설정 — 미설정 (데모 모드)
키는 이 브라우저의 localStorage에만 저장되며 어디로도 전송되지 않습니다(YouTube API 제외). 발급: Google Cloud Console → 프로젝트 생성 → YouTube Data API v3 사용 설정 → 사용자 인증 정보 → API 키. 무료 할당량 1일 10,000 유닛 (채널 1개 정밀 분석 ≈ 3~5 유닛, 이름 검색 시 +100 유닛).
AI 훅 분석 설정 — 미설정 (사용 안 함)
아래 영상 목록의 훅 분석 버튼을 누르면 그 영상의 제목·설명·썸네일이 분석 시점에 Anthropic API로 전송됩니다 — YouTube 키와 달리 이 키를 넣으면 외부 서비스로 데이터가 나갑니다. 키는 이 브라우저의 localStorage에만 저장됩니다. 발급: Anthropic Console. 호출마다 소액 과금되며, 설정하지 않아도 나머지 모든 기능은 그대로 사용할 수 있습니다.
